# Runner — домашнее задание 2 (HA_2)

## Разработчик

 

## О проекте

Бесконечный раннер на Unity: игрок движется по полосам, уклоняется от препятствий, набирает очки за время выживания. В **HA_2** добавлены бонусы, полноценный одно-сценовый игровой поток (меню → игра → пауза / game over), сохранение лучшего результата и визуальный отклик на урон и бонусы.

## Точка входа и сцены

| Элемент | Путь / объект |
|--------|----------------|
| **Единственная сцена сборки** | `Assets/Scenes/SampleScene.unity` |
| **Точка входа** | Запуск сцены в редакторе или билд — инициализация объектов сцены, синглтон `GameManager` переводит игру в состояние главного меню в `Start()`. |
| **Главные скрипты** | `GameManager` — состояния и скорость; `PlayerController` — ввод и столкновения; `ObstacleSpawner` — платформы и спавн бонусов; `PlayerUIUpdater` — панели меню / HUD / паузы / game over; `GameEvents` — событийная шина для UI и фидбека. |

Настройка сцен в билде: `ProjectSettings/EditorBuildSettings.asset` — включена только `SampleScene`.

## Логика (кратко)

1. После загрузки сцены показывается **главное меню**; по кнопке «Старт» сбрасывается мир, игрок жив, время идёт, очки растут как целая часть секунд с начала забега.
2. Скорость мира растёт со временем (параметры у `GameManager`), препятствия и платформы спавнятся через `ObstacleSpawner`; с заданной вероятностью на платформе может появиться **бонус** (префабы и шанс задаются в `ObstacleConfig`).
3. Столкновение с препятствием наносит урон (`PlayerData`); при активной неуязвимости урон игнорируется. HP падает до нуля — событие смерти, **game over**, при новом рекорде значение пишется в `PlayerPrefs` через `HighScoreStorage`.
4. **ESC** в игре открывает паузу (`Time.timeScale = 0`); из паузы и game over можно вернуться в главное меню с пересборкой мира.

## Реализованные функции (HA_2)

- Два типа бонусов (data-driven `ScriptableObject`): **лечение** (`BonusHeal`), **временная неуязвимость** (`BonusInvulnerability`).
- Подбор через триггер у `PlayerController`, определения в `Assets/Configuration/BonusData/`, префабы в `Assets/Prefabs/Bonuses/`.
- UI: главное меню (старт, выход, лучший счёт), HUD (здоровье, счёт, лучший счёт, статус бонуса), пауза (продолжить / в меню), экран game over.
- Сохранение **high score** между сессиями (`HighScoreStorage`, ключ `Runner.HighScore`).
- Визуальный фидбек: вспышка урона, реакция на подбор бонуса, мигание на время неуязвимости (`PlayerVisualFeedback`, DOTween).

## Сторонние материалы и плагины

- **DOTween** (Demigiant) — анимации и визуальный фидбек.
- **TextMesh Pro** — UI.
- **Fantasy Skybox FREE** — окружение / небо (если используется в сцене).
- **Universal Render Pipeline (URP)** — рендер (версия Unity см. ниже).

Версия редактора (из `ProjectSettings/ProjectVersion.txt`): **Unity 6000.3.9f1** (Unity 6).

## Изменения по сравнению с HA_1

| Было (HA_1) | Стало (HA_2) |
|-------------|----------------|
| Упрощённый поток без полноценного меню в сцене | Одна сцена: меню, игра, пауза, game over управляются `GameManager` и UI |
| Нет сохранения рекорда | Лучший счёт в `PlayerPrefs` |
| Только препятствия и базовый HUD | Бонусы SO + пикапы, расширенный HUD и статус эффектов |
| Авто-рестарт / минимальный UX после смерти | Явный game over и возврат в меню / новый забег по кнопкам |
| Минимальный или отсутствующий фидбек | Отдельный компонент визуального отклика на урон и бонусы |
